Set Up Your Round Weather Display

ESP32-P4 (Waveshare 3.4C round display) — flash it straight from this page, no software install needed.

Before you start: this only works in Chrome, Edge, or Firefox on a Windows, Mac, ChromeOS, or Linux computer. It does not work in Safari, and it does not work on an iPhone or iPad at all (Apple doesn't allow it). Android phones aren't supported either — you'll need an actual computer.

Step 1: Connect and Flash

  1. Plug your ESP32-P4 board into your computer with a USB-C cable. (Make sure it's a real data cable — some cables that come with chargers are power-only and won't work here.)
  2. Click the button below.
  3. Your browser will show a list of devices — pick the one that looks like your board (it may show up as "USB JTAG/serial debug unit" or similar).
  4. Click Install. It'll take a couple of minutes — don't unplug the board or close this tab while it's working.

First time setting this board up? Choose "Install" (it'll erase and start fresh). Already have it running and just want the newest version? Same button — pick "Install" again to update.

Your browser can't do this

This page needs a feature called Web Serial, which is only available in Chrome, Edge, or Firefox on a desktop computer. Please open this page again in one of those browsers.

Step 2: Finish setup on the device itself

Once flashing finishes, the round display will boot up on its own and walk you through the rest right on the screen:

  • Connecting to your WiFi network (it'll show you a list of nearby networks to pick from, with an on-screen keyboard for the password)
  • Setting your location, so it knows what weather to show
  • Naming the room it's in and choosing a few display preferences

You don't need this computer for that part — it's all done by touching the display.

Something not working?

  • Don't see your device in the list? Try a different USB cable (it needs to carry data, not just power), or try a different USB port.
  • Install button greyed out or missing? Double check you're using Chrome, Edge, or Firefox — not Safari.
  • Still stuck? Open an issue on the project's GitHub page.

Prefer building from source, or setting up a Raspberry Pi instead? See the main project page.
